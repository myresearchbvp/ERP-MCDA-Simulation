# Sample outputs

This folder contains example files exported from the interactive Colab notebook.

The files in `baseline_s1/` correspond to the baseline S1 configuration used in the article, with the sensitivity analysis activated before export.

## Files

- `ERP_Selection_Report_baseline_s1.txt` – text report generated by the tool.
- `ERP_Raw_Data_baseline_s1.csv` – raw score matrix exported from the tool.
- `ERP_DSS_Charts_baseline_s1_with_sensitivity.png` – composite chart exported from the tool after running sensitivity analysis.

These files are provided only as reproducibility examples. Users can generate new outputs by running the notebook, changing weights or scores and using the export buttons.
